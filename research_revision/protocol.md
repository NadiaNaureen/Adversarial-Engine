# Revision evaluation protocol

Frozen before test evaluation, 23 October 2026.

Five population seeds: 11, 22, 33, 44, 55. Each auxiliary index has 10,000 synthetic identities, generated without forcing profile uniqueness. Age depends on occupation; medical-flag prevalence depends on age. Records are entirely synthetic and are not representative estimates of any real population. Medical flag is assumed known to this attacker; it is not an inference endpoint.

Validation and test identities are disjoint. Each split includes equal numbers of present and absent identities. Absent identities are independently sampled, including accidental profile collisions. Each identity produces clean, age plus/minus one, missing occupation, changed occupation, combined noise, and semantic occupation paraphrase targets. Related variants remain in the same split. Validation has 20 present and 20 absent identities per seed; test has 30 present and 30 absent. The cloud subset contains the first five present and five absent identities in each split, all six conditions, selected before seeing predictions.

Compare exact compatible matching, supervised Fellegi-Sunter log-likelihood linkage, local 256-dimensional hashed retrieval with deterministic verification, always-top candidate, and margin-disabled verification. Exact matching abstains on incomplete evidence and multiple matches. Fit Fellegi-Sunter field agreement distributions on independent synthetic training pairs; select thresholds only on validation targets. Retrieval k is selected from 4, 8, 16; frequency-weight cap from 1, 3. Score threshold grid 0.50 through 0.80 in 0.05 increments; margin grid 0, 0.04, 0.08, 0.12. Maximize validation correct-link rate subject to absent FPR <= 0.05 and present wrong-link rate <= 0.05; break ties by precision, then stricter thresholds. If no setting meets constraints, choose minimum combined error then maximum recall. Freeze per-seed settings before test.

Cloud: identical candidate pools and cloud subset targets; Gemini semantic embedding retrieval with deterministic verification versus the same retrieved candidates with Gemini nomination and programmatic verification. Fit operating thresholds on cloud validation targets independently. No cloud-to-local fallback. Failed calls and invalid outputs remain explicit failures and count in end-to-end denominators. Cloud embeddings use exact cosine search rather than approximate Chroma retrieval to isolate representation effects. Synthetic names are opaque IDs and never appear in embedding inputs.

Mitigation: apply original, age decade, postal three-digit prefix, medical suppression, occupation suppression, combined, and globally generalized k=5 release to the 60 clean test records per seed. Verify k over four quasi-identifiers (age, postal code, occupation, gender); medical flag is sensitive content, and is additionally known in this strong attacker experiment. Calculate k on released records, not the auxiliary index. Use predefined generalization ladders; if necessary suppress all four QIs to attain k. Audit transformed records against unchanged original auxiliary records. Use clean-validation settings for mitigation comparisons. Report changes, suppression, normalized information loss over five fields, and age-decade/occupation marginal total-variation error. No formal DP or sensitive-attribute guarantee is claimed.

Outcomes: correct present links, wrong present links, present abstentions, absent false links, absent abstentions; ambiguous/insufficient/error decisions are separately saved. Precision = correct / all issued identities; recall = correct / present; absent FPR = absent false / absent; coverage = all issued identities / all targets. Confidence intervals are not inferred from correlated target variants. Primary variability is mean and sample SD across five seeds. Sensitivity curves are descriptive test sweeps and are not used to reselect settings.

All source datasets, prediction rows, configurations, raw model outputs, provider usage, API errors, timings, and source hashes are retained. Existing historical summary is superseded, not retroactively repaired without original predictions. Local benchmark runs are isolated from the app's persistent Chroma index. Cloud billing cost is only reported if actual billing data is available; tokens and elapsed time are measured separately.
