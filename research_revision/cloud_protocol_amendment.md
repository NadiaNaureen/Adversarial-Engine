Compare Gemini nomination plus deterministic verification against the identical full 10,000-person local-retrieval candidates. Also report local results on this exact target subset.

The provider subsequently reported a 1,000-input daily embedding quota in addition to its minute quota. After the indicated daily reset, separately construct a 150-person semantic pilot index per seed containing all 50 validation/test present identities and 100 random background identities. Five indexes and 240 query inputs require 990 embeddings, within that daily quota. This scope amendment precedes semantic target predictions. Compare hash retrieval, Gemini semantic retrieval, and semantic retrieval plus Gemini nomination on identical pilot indexes and selected targets. This index intentionally enriches target presence and is a controlled component pilot, not a scale result or a population estimate. Do not compare pilot recall directly against the 10,000-person main table as evidence of representation superiority. Pilot operating thresholds use only pilot validation labels. Results are descriptive due to only two present and two absent base identities per seed. Quota failures, invalid JSON, and provider omissions remain explicit. No silent fallback.

The confirmed chat limit is 15 requests per minute. A shared scheduler spaces new assessment calls at least 4.3 seconds apart. Rate-limited records are retried after quota delay; provider failures are never interpreted as model abstentions. Final model-quality tables require valid completed responses. Representative quota responses are retained. Earlier failed cache entries were replaced by completed responses during retry, so this is not a complete per-attempt billing log; failed-attempt usage is unavailable and excluded from the cost estimate.

The chat prompt is standardized for the benchmark and differs in wording from the dashboard prompt while retaining its supplied-candidate constraint. Deterministic field compatibility remains the application scorer. The pilot tests that scorer's semantic bottleneck rather than silently changing occupation agreement to accept model assertions.
